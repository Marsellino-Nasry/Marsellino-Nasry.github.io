01Overview

Network-X applied a full penetration-testing methodology to a real environment: the academy's network and public website. The work covered network administration and security, including Layer 2 attacks, and finished with a proposed network redesign that adds security operations capabilities.

02Problem statement

Academic networks are open by design, used by many people and rarely tested the way an attacker would approach them. The academy needed an evidence-based view of where its network and website were vulnerable, and a practical plan to fix them.

03Objectives

  • Assess the network infrastructure for exploitable weaknesses.
  • Evaluate the website's security posture.
  • Rate every finding consistently and recommend remediation.
  • Propose a redesigned network that is easier to defend and monitor.

04Methodology

  1. Preparation

    Passive reconnaissance, WHOIS and DNS enumeration.

  2. Scanning

    Network and web application scanning.

  3. Enumeration

    Service and directory enumeration.

  4. Vulnerability assessment

    Automated and manual checks for outdated software, misconfiguration and weak permissions.

  5. Exploitation and post-exploitation

    Controlled, simulated attacks to confirm severity and potential impact.

  6. Reporting

    Findings rated by CVSS with remediation steps.

06Deliverables

Vulnerability assessment of the academy's public website.

Network redesign

A Packet Tracer design proposing segmentation and security operations technologies.

07Implementation

The test followed the phases above from passive reconnaissance to reporting. Automated scanning found candidate issues; manual verification and controlled exploitation confirmed which ones were real and how severe they were. The redesign then addressed the root causes the findings pointed to, rather than each issue in isolation.

This was the project where the two halves of my work first met: an offensive engagement that ended in an assurance-style report.

08Security considerations

  • Authorised scope: the test was an approved academic project on the academy's own environment.
  • Controlled exploitation: attacks were simulated to confirm impact without disrupting the network.
  • Responsible reporting: findings went to the academy with remediation guidance.
