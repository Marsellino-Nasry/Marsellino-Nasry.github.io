01Overview

The ISMS Assurance Platform brings the core artefacts of an ISO/IEC 27001:2022 engagement into a single browser application: the management-system clauses, all 93 Annex A controls, the Statement of Applicability, the risk register, findings and corrective actions, and the evidence behind each conclusion.

It is a support tool for auditors and implementers. It does not certify anything, and it is not affiliated with or endorsed by ISO or IEC.

02Problem and objectives

Problem

ISMS audits and implementations usually run on a patchwork of spreadsheets, templates and email. The SoA lives in one file, the risk register in another and findings in a third, so the links between a risk, the control that treats it, the evidence that proves it works and the finding raised when it does not are easy to lose.

Commercial GRC suites solve this, but they are expensive, server-hosted and often a poor fit for a single auditor or a small organisation that cannot send sensitive security data to a third-party cloud.

Objectives

  • Cover the full standard: Clauses 4 to 10 and every Annex A control, with ISO/IEC 27002:2022 attributes.
  • Keep risks, controls, SoA entries, findings and evidence connected in one place.
  • Produce audit-ready PDF and spreadsheet outputs without manual reformatting.
  • Keep sensitive working data on the user's own device, with no server and no account.
  • Run anywhere a modern browser runs, with nothing to install.

07Implementation

The platform is a static web application with no build step, hosted on GitHub Pages. Each module works on a shared assessment model, so a risk in the register can reference the Annex A controls that treat it, and those controls carry their applicability, implementation status and evidence through to the SoA and the final report.

Charting, spreadsheet and PDF generation are handled by established open-source libraries rather than custom code, which keeps the application small and the outputs in formats auditors already use.

Version 1, published as the ISO 27001 Ultimate Platform (opens in a new tab), established the Annex A, SoA, risk register and reporting core. Version 2 reorganised the product as the ISMS Assurance Platform, adding the clause-level conformity assessment, the findings workflow and maturity indicators.

08Security considerations

Data residency

Assessment data is held in the user's browser and only leaves the device when the user exports it.

No accounts

There are no credentials to steal and no multi-tenant database to breach.

Backups are the user's responsibility

Clearing browser data removes working data, so regular JSON exports are recommended.

Third-party libraries

Some libraries load from public CDNs. Organisations with strict policies should self-host them and review the source, as the repository README advises.

Sample outputs

Sample reports in the repository are fictional and should be labelled as demonstrations when shared.
